# 🏎️ Mercedes F1 Performance Analytics (2021–2025)

An end-to-end Formula 1 analytics project exploring Mercedes
team performance using Python, SQL, and Power BI.

## 🛠️ Tools & Technologies
- Python: Pandas, data cleaning, exploratory data analysis
- SQL: Performance analysis, ranking, and aggregation
- Power BI: Interactive performance dashboard

## 🔍 Project Objectives
- Analyze team performance across the 2021–2025 seasons
- Compare driver performance and race results
- Explore qualifying positions, finishing positions, and circuits
- Investigate reliability and DNF trends
- Present insights through an interactive Power BI dashboard
